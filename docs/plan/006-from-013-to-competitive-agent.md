## 2. 三个足以改变旧计划的新事实

### 2.1 官方允许小模型，12B成为独立训练路线

## 3. 高分Notebook真正支持什么

本轮读取ScoreDescending和DateRun各前30、10份完整源码，并用页面徽章绑定精确版本。可核实完整源码仍最高0.18：Budget-Fit V5（355310852）、Budget-Aware V9（356722956）。两者同源、都是无训练单Agent，不算两份独立机制复现。没有找到能对应0.20+分数的完整公开源码。

其共同设置是8192输出预留、thinking4096、8分钟/28工具调用、局部读改和短验证。但所有变量一起变化，不能把0.18单独归给8192或8分钟；我们旧0C为16384 7/12对8192 6/12，暂无净增。源码仍应作为强参考，而不是当作已发现榜首秘密。

Sam现V4的0.18属于旧V1；Apex标题0.24没有对应评分；“Gold Submit”只是打包既有配置；“Gemma+Gemini”实际模型声明全为Gemma且包含多份历史候选。禁止根据标题、热度、父本或作者队伍分数认定当前源码有效。

新公开工具研究中105/524次edit/write被缺参数拒绝、集中15题；47次代码进入参数名，同一错误最多重发14次。它与本地循环一致，但尚不能区分模型生成与parser责任。单字符串编辑入口值得作为后续候选，**工具错误减少必须转化为正确修复才有价值**；robust-edit三轮6/16对6/16的反证仍在。

新版图工具314次旧调用中270次有返回、122次含参考修改文件节点；这是重放/检索证据，不是修复收益。旧“图必空”应撤回，但大回包可能加剧上下文负担，只在文本定位有具体歧义时另测少量邻居。
