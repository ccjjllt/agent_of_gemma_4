# 从读到源码到做成修改：机制研究，2026-10-01

本研究发现的主要机会是**提高已取得源码证据向有效修改的转化**，并让复现真正区分题目中的故障子条件。它不是新策略的实测成绩，也不证明检索已经解决。

范围：P003 smoke 3＋探索18＋面板48，共69条轨迹；P002 0C有24份结果、23条轨迹。合计93次结果、92条可读轨迹，覆盖27个已经暴露的task_id。未运行模型、GPU/AMD/TPU、测试或新实验，未改冻结配置或历史标签。

## 最有解释力的数量

67次raw失败来自24个不同task_id，不是67道独立题。它们的trace均可读。

| 观察 | 运行次数 | 含义与限制 |
|---|---:|---|
| 成功read_file读过gold修改的生产文件 | 61/67（91.0%），来自21题 | **不是91%已定位正确**；只证明某次工具成功返回同一文件的片段。没有证明读到正确函数、理解根因或及时取得证据。 |
| 60秒内已读到该文件 | 55/67 | 同样只是文件级接触；不保证片段相关。 |
| 成功读取内容含gold删除行的长文本锚点 | 54/67 | 弱区域代理，不能当理解证据。 |
| 已读到文件，但后来没有成功生产edit/write | 37/61 | 不含run_command里可能进行的编辑；可由最终patch进一步交叉判断。 |
| 文件命中→首次成功生产edit/write | 失败中24次可算，中位125.3秒 | 条件子集；成功中21次可算，中位131.8秒，不能因此宣称越早编辑就越成功。 |

成功26次，其中25条trace可读。四条成功未出现上述read_file命中，不等于没有读源文件，命令行也可以读取。唯一缺失trace为0C的`23-rich_3518-r2-t0`，结果保留成功，过程指标保持缺失。

文件命中的原始分批数：smoke失败2/2；探索12/12；面板36/42；0C 11/11。各批次环境、策略和重复次数不同，不能直接合并成一个策略成功率。

作为敏感性描述，仅按**任务ID属于后来0B九题eligible名单**分组，得到25次失败/8题，25次都读到gold文件，24次未成功生产edit/write。分批为smoke 1/1、探索3/3、面板14/14、0C 7/7。这不证明旧运行环境也具有后来测得的验证资格，不能作为修正后的历史分数。

“锚点”的机械定义：在成功read_file返回的gold文件内容中，寻找任意一条去首尾空白后长度≥20的gold删除行子串。通用语句也可能命中；没有合格删除行的补丁没有锚点。因此它既不是正确函数覆盖率，也不是理解率。

每例完整的run、trace路径/SHA、step、时间、工具输入短摘录、实际反馈及最终生产文件都保存在[casebook.json](casebook.json)。不导出长thinking全文。

M08、M09存在已知验证资格问题，只分析动作机制，不将最终失败归因为模型修复失败。M05的潜在节时是历史反事实；M06不是对缺失轨迹的“全局最短”断言。案例之间并非新机制的随机对照，均需后续冻结实验。

## 最值得尝试的策略与顺序

1. **S2：局部编辑事务（主交接T2方向）**。读取产生可引用的精确源码片段/句柄；模型指定最小语义变更；旧串失败后只允许回读并缩小操作，不原样重试；立即重跑同一见证。主要检验“读到相关文件→成功生产修改”的转化率和最终修复。文件命中本身不足以授权无根据改动。
2. **S1：有区分力的反例合同（主交接T3方向）**。从issue提取触发轴、邻近对照、目标断言；全绿时优先检查是否遗漏故障子条件。相同输入、相同输出、无源变化的两轮之后，下一步必须增加信息或执行局部修改。合同可被新证据修订，不能僵化。
3. **S3：证据闭环后的条件收尾**。目标反例fail→pass、一个相关邻近对照不退化、最终diff/语法/文件集合检查通过后，submit一次并停止。主动提交率不是主指标；以配对resolved和回退为主。

这是可提交skill/提示使用纪律的研究交接，尚未实现这些新策略。不改现有冻结T0/T1，不与capacity、thinking、图检索、硬件或LoRA同时变更；分层上下文研究另立。T2先于T3是当前交接选择，不是已测优越性。

## 历史oracle只作上界诊断

在全部27题上，从已经观察到的不同策略/重复中事后挑一次成功，可覆盖7个task_id；限定同一24题面板，跨历史记录可覆盖6题：fastapi_11194、fastapi_14873、fastapi_9425、requests_6644、rich_2725、rich_3518。

这使用了额外计算和事后答案，**不是新策略的7/27或6/24成绩**，也不是模型能力的理论上限。其中requests_6644在后来的空补丁校准已通过，更不能把其raw成功当作修复收益。

## 复现与边界

仅Python标准库，在仓库根目录：

```sh

python3 research/002/mechanism-study-20261001/build_casebook.py
```

`collect.py`从两张P003 CSV确定27个已暴露ID，并与heldout互斥检查；逐行先按ID过滤`/private/tmp/gemma4-research/tasks.jsonl`，只解析允许行。输出`evidence.json`，包含所有93次结果索引、92条轨迹的工具事实、输入哈希、文件/锚点命中和过程指标。
