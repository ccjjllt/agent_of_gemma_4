# Gemma 4 Dev Agent: contract-first single-agent bundle

Builds, validates and zips a `submission.zip` from the optimization blueprint: one agent, five tools, hard budgets, contract-first prompt, thinking on. Every number lives in one config cell, and the prompt and `eval_config.yaml` are generated from it so they cannot drift apart.

Not run against the scorer. Treat it as a starting bundle, and compare variants on several runs or a local eval, because one public score is about +/-0.08.

Where the blueprint and the harness spec disagree, this notebook follows the spec and says so (section 11).

# CELL 7 markdown
## 4. The 12-hour budget
Hidden tasks run one after another and the whole run must finish in 12 hours. The check below uses the config above. The worst case assumes every task runs to the time cap; the break-even rows show how many may.

# CELL 8 code
def worst_case_hours(cap_min, n=CFG["n_hidden_tasks"], overhead=CFG["overhead_min"], fixed=CFG["fixed_setup_min"]):
    return (n * (cap_min + overhead) + fixed) / 60

def max_mean_minutes(n=CFG["n_hidden_tasks"], overhead=CFG["overhead_min"], fixed=CFG["fixed_setup_min"], limit_h=12):
    return (limit_h * 60 - fixed) / n - overhead

print(f"{'cap (min)':>9} | {'worst case (h)':>14}")
for cap in (4.5, 5.0, 6.0, 7.0, CFG["max_time_minutes"]):
    print(f"{cap:>9} | {worst_case_hours(cap):>14.1f}")

mean_ok = max_mean_minutes()
print(f"\nmean agent time per task must stay under {mean_ok:.2f} min to fit 12 h")

cap = CFG["max_time_minutes"]
for early in (2, 3, 4):   # assumed average minutes for tasks that stop before the cap
    f_max = (mean_ok - early) / (cap - early)
    print(f"if early-stopping tasks average {early} min, at most {f_max:.0%} of tasks may run to the {cap}-min cap")

# CELL 9 markdown
The tool-call cap is what keeps the mean low, not the time cap. The blueprint's own arithmetic says a 6-minute cap can overrun in the worst case, yet it recommends 8; that works only if most tasks stop early. If you raise `max_tool_calls`, lower `max_time_minutes`.

# CELL 14 code
import math

def binomial_ci(p, n, z=1.96):
    se = math.sqrt(p * (1 - p) / n)
    return p - z * se, p + z * se

n_public = 60   # about half of ~120 hidden tasks
for p in (0.12, 0.18, 0.24):
    lo, hi = binomial_ci(p, n_public)
    print(f"true rate {p:.2f}: one public score lands in about [{lo:.2f}, {hi:.2f}] 95% of the time; one task = {1/n_public:.3f}")

# CELL 15 markdown
## 7. The prompt and configs
The prompt is a contract: it says what wins (a non-empty source diff), what is forbidden (tests, graph tools, `pip`), and when to edit. Notes on the choices:

- Step 1 forces plain text before the first tool call. That doubles as the workaround for the vLLM `gemma4` reasoning-parser issue where a channel-less first reply is swallowed as reasoning.
- Navigation uses `git grep`, not `rg`: git is guaranteed in the sandbox image, ripgrep is not documented there.
- The harness appends a "Code Intelligence Tools" section to the task prompt when graph data exists, so the prompt explicitly says those tools are not registered.
- The grader resets test files and runner configs (`conftest.py`, `pytest.ini`, `pyproject.toml`, `tox.ini`, `setup.cfg`, ...) before running hidden tests, so edits there are wasted calls.
- No `{name}` placeholders in the prompt: ADK would try to fill them from session state.

# CELL 16 code
SYSTEM_PROMPT = f"""You fix one issue in the repository at /workspace with the smallest source change.
Hidden tests are applied to your git diff afterwards. An empty diff scores zero.

Budget: {CFG['max_tool_calls']} tool calls, {CFG['max_time_minutes']} minutes. When either runs out, the working tree is graded as it is. submit_patch does not count as a tool call.
Environment: offline, dependencies already installed, never pip install. Your tools are run_command, read_file, edit_file, write_file and submit_patch. The code-graph and similarity tools named in the task text are not available; never call them.

1. Before any tool call, write out in plain text the exact names, messages, status codes and return values the issue requires. Use them character for character.
2. Locate with one `git grep -n "<most specific string>" -- '*.py' | head -20`, then read at most {CFG['read_window_lines']} lines around the hit.
3. By your {CFG['edit_by_call']}th tool call a source file must be edited. If unsure, edit the most likely function now.
4. edit_file: old_string is 3 to 5 lines containing something unique; new_string is the complete final code, never a placeholder such as "# rest unchanged". Prefer several small edits to one large one.
5. Run at most one focused check (`pytest path::test -q` or `python -c ...`). Never run bare pytest. Fix only assertion failures about your change. Ignore fixture, import or pre-existing failures.
6. Scratch files go in /tmp. Never create or edit tests, conftest.py, pytest.ini, pyproject.toml, setup.cfg or tox.ini; the grader discards those changes.
7. Run `git diff`, revert any test path with `git checkout --`, then call submit_patch once.
"""

# CELL 17 markdown
## 8. Validate before spending a daily submission
Only one submission can be pending at a time and queues run long, so a malformed bundle costs a day. This is a dependency-light mirror of the host's hard checks (PyYAML only), plus warnings for the traps this bundle is built to avoid.

# CELL 18 code
import pathlib, yaml

ALLOWED_EXT = {".yaml", ".yml", ".md", ".txt", ".py", ".json", ".safetensors"}
ROOT_NAMES = ["agent.yaml", "agent.yml", "root_agent.yaml", "root_agent.yml"]
KNOWN_TOOLS = {"run_command", "submit_patch", "get_status", "read_file", "edit_file", "write_file",
               "get_code_neighbors", "search_similar_code", "get_code_subgraph"}
GRAPH_TOOLS = {"get_code_neighbors", "search_similar_code", "get_code_subgraph"}
BANNED_GEN_KEYS = {"tools", "system_instruction", "http_options", "safety_settings", "response_schema"}

def load_with_includes(path, root, depth=0):
    if depth > 10:
        raise ValueError("include depth > 10")
    class Loader(yaml.SafeLoader):
        pass
    def _inc(loader, node):
        ref = loader.construct_scalar(node)
        target = (path.parent / ref).resolve()
        if root.resolve() not in target.parents:
            raise ValueError(f"include escapes bundle: {ref}")
        if not target.is_file():
            raise FileNotFoundError(f"include missing: {ref}")
        if target.suffix in (".yaml", ".yml"):
            return load_with_includes(target, root, depth + 1)
        return target.read_text(encoding="utf-8")
    Loader.add_constructor("!include", _inc)
    return yaml.load(path.read_text(encoding="utf-8"), Loader=Loader)

def collect_agents(path, root, seen=None):
    seen = seen if seen is not None else set()
    path = path.resolve()
    if path in seen:
        return []
    seen.add(path)
    cfg = load_with_includes(path, root)
    out = [(path, cfg)]
    refs = [s.get("config_path") for s in cfg.get("sub_agents", []) or []]
    refs += [t["agent_tool"].get("config_path") for t in cfg.get("tools", []) or []
             if isinstance(t, dict) and "agent_tool" in t]
    for ref in filter(None, refs):
        out += collect_agents(path.parent / ref, root, seen)
    return out

def validate(root, verbose=True):
    root = pathlib.Path(root)
    block, warn = [], []
    if not root.exists():
        print(f"no directory at {root}"); return False
    roots = [n for n in ROOT_NAMES if (root / n).exists()]
    if len(roots) != 1:
        block.append(f"need exactly one root config, found {roots}")
    files = [p for p in root.rglob("*") if p.is_file()]
    links = [str(p.relative_to(root)) for p in root.rglob("*") if p.is_symlink()]
    if links: block.append(f"symlinks not allowed: {links}")
    bad = [str(p.relative_to(root)) for p in files if p.suffix.lower() not in ALLOWED_EXT]
    if bad: block.append(f"disallowed extensions: {bad}")
    total = sum(p.stat().st_size for p in files)
    if total >= HARNESS["size_limit"]: block.append(f"bundle too big: {total} bytes")

    agents = []
    if roots:
        try:
            agents = collect_agents(root / roots[0], root)
        except Exception as e:
            block.append(f"config does not load: {e}")
    models, tools_seen = set(), set()
    for path, cfg in agents:
        if not isinstance(cfg, dict):
            block.append(f"{path.name}: not a mapping"); continue
        if cfg.get("model"): models.add(str(cfg["model"]).split("/")[-1])
        if cfg.get("sub_agents"): warn.append(f"{path.name}: sub_agents present (multi-agent gave +1 task of 129 in the ablation)")
        if cfg.get("skills"): warn.append(f"{path.name}: skills present (run_skill_script can crash a task on a malformed argument)")
        if cfg.get("adapter"):
            ad = root / "adapters" / str(cfg["adapter"])
            if not ((ad / "adapter_config.json").exists() and (ad / "adapter_model.safetensors").exists()):
                block.append(f"{path.name}: adapter {cfg['adapter']} missing adapter_config.json / adapter_model.safetensors")
        for t in cfg.get("tools", []) or []:
            if isinstance(t, str):
                tools_seen.add(t)
                if t not in KNOWN_TOOLS: block.append(f"{path.name}: unknown tool {t!r}")
        if isinstance(cfg.get("instruction"), str) and re.search(r"\{\+?[A-Za-z_]\w*\??\}", cfg["instruction"]):
            warn.append(f"{path.name}: instruction has a {{name}} placeholder; ADK fills those from session state")
        gen = cfg.get("generate_content_config") or {}
        if BANNED_GEN_KEYS & set(gen): block.append(f"{path.name}: forbidden generate_content_config keys {sorted(BANNED_GEN_KEYS & set(gen))}")
        mot = gen.get("max_output_tokens")
        if mot is not None and not 1 <= mot <= HARNESS["max_model_len"]: block.append(f"{path.name}: max_output_tokens {mot} out of range")
        tc = gen.get("thinking_config") or {}
        if tc.get("thinking_budget", 0) > HARNESS["max_model_len"]: block.append(f"{path.name}: thinking_budget too large")
        if "thinking_level" in tc: warn.append(f"{path.name}: thinking_level set; on vLLM use thinking_budget + include_thoughts instead")
        if gen and (tc.get("include_thoughts") is False or tc.get("thinking_budget") == 0):
            warn.append(f"{path.name}: thinking is off or hidden (23 and 35 tasks vs 48 and 51 in the ablation)")
        if gen and not tc: warn.append(f"{path.name}: no thinking_config")
        if mot and mot + HARNESS["compaction_threshold"] > HARNESS["max_model_len"]:
            warn.append(f"{path.name}: max_output_tokens {mot} leaves no room above the compaction threshold")
    if len(models) != 1: block.append(f"must declare exactly one base model, found {sorted(models)}")
    elif models != {CFG["model"]}: block.append(f"base model must be {CFG['model']}, found {sorted(models)}")
    if tools_seen & GRAPH_TOOLS: warn.append(f"graph tools registered: {sorted(tools_seen & GRAPH_TOOLS)} (floods the 32k context; semantic search returned nothing offline)")
    if "submit_patch" not in tools_seen and agents: warn.append("submit_patch not registered")

    ev = root / "eval_config.yaml"
    if not ev.exists():
        warn.append("no eval_config.yaml: default 60 min per task would blow the 12 h limit")
    else:
        e = (yaml.safe_load(ev.read_text()) or {}).get("evaluation", {})
        unknown = set(e) - {"timeout_seconds", "max_tool_calls", "max_time_minutes", "max_turns"}
        if unknown: block.append(f"eval_config.yaml unknown keys {sorted(unknown)}")
        cap = e.get("max_time_minutes")
        if cap is None: warn.append("eval_config.yaml: no max_time_minutes")
        elif worst_case_hours(cap) > 12: warn.append(f"worst case {worst_case_hours(cap):.1f} h at a {cap}-min cap; fits 12 h only if enough tasks stop early (see section 4)")
        if e.get("max_tool_calls") is None: warn.append("eval_config.yaml: no max_tool_calls")
        elif e["max_tool_calls"] < 25: warn.append(f"max_tool_calls {e['max_tool_calls']} is low (25 vs 50 cost 14 tasks in the ablation)")

    if verbose:
        for w in warn: print("warn :", w)
        for b in block: print("BLOCK:", b)
        if not block:
            print(f"OK: 1 root, model {sorted(models)}, tools {sorted(tools_seen)}, {len(files)} files, {total} bytes")
    return not block

# CELL 20 code
import shutil, tempfile, zipfile

BUNDLE = pathlib.Path("/kaggle/working/submission") if pathlib.Path("/kaggle/working").is_dir() else pathlib.Path("submission")
shutil.rmtree(BUNDLE, ignore_errors=True)
for name, text in FILES.items():
    p = BUNDLE / name
    p.parent.mkdir(parents=True, exist_ok=True)
    p.write_text(text, encoding="utf-8")

if validate(BUNDLE):
    out = BUNDLE.parent / "submission.zip"
    with zipfile.ZipFile(out, "w", zipfile.ZIP_DEFLATED) as z:
        for p in sorted(BUNDLE.rglob("*")):
            if p.is_file():
                z.write(p, p.relative_to(BUNDLE).as_posix())
    names = zipfile.ZipFile(out).namelist()
    assert "agent.yaml" in names, "agent.yaml must sit at the archive root"
    with tempfile.TemporaryDirectory() as tmp:
        zipfile.ZipFile(out).extractall(tmp)
        print("round-trip:", end=" "); validate(tmp)
    print("wrote", out, names)

# CELL 23 markdown
## 11. Where this differs from the blueprint, and why

- **Time cap.** The blueprint's own math says a 6-minute cap can overrun the 12 hours in the worst case, then recommends 8 minutes. Kept at 8 with 28 calls because that pairing is what the 0.18 public bundle used, but section 4 shows the condition under which it fits.
- **`rg` vs `git grep`.** The blueprint's text names ripgrep, its final prompt uses `git grep`. The prompt here uses `git grep` since git is the documented tool in the image.
- **Unregistered graph tools.** The harness still advertises them in the task prompt when graph data exists; the system prompt now tells the model they do not exist.
- **Edit rules.** The blueprint's analysis asks for short unique `old_string` blocks and no placeholders but its prompt omits them; added as step 4.
- **Thoughts hidden.** The 16-task loss is measured against the temperature 1.0 run (51 to 35), not the 48-task reference.
- **No skills.** The blueprint reports a `run_skill_script` crash on a list-valued `file_path`. I could not confirm that from the harness spec, and a public bundle with a script skill scored 0.17, so treat it as unverified; this bundle avoids skills either way and the validator warns if you add one.
- **`get_status`.** Left out as in the blueprint: the harness already injects a budget warning near the end, and an extra tool is an extra thing to misuse.

## 12. LoRA, briefly
The blueprint's advice stands: SFT on trajectories from other harnesses (`bash`, `str_replace_editor`) teaches tool names this harness cannot parse. Only harness-native traces from `results/<run>/traces/`, filtered to resolved tasks and formatted exactly as vLLM renders them, are worth training on. Smoke-test a small adapter end to end before investing days, and keep the total bundle under 3 GiB.
