**TL;DR**

- The competition scores the fraction of repository issues whose agent patch passes hidden tests. It accepts a ZIP of agent configuration and optional LoRA weights, not a CSV.
- This notebook builds unified-diff examples from public development fixes. It withholds the **entire Rich repository** from training and masks loss on the issue/context prompt.
- Rich held-out loss is a component signal, **not** a solved-issue score. The final adapter must load and solve issues under the official harness.
- The notebook writes a PEFT adapter and a **candidate** `submission.zip`; the training checkpoint differs from the competition's QAT serving base, so adapter load and patch quality require an official harness check.
- **This is one offline training notebook:** Save & Run All trains and writes `submission.zip`. Choose that successful version under the competition's **Notebook** submission tab; Kaggle reruns its training code with a separate frozen public training Input.

# CELL 1 markdown
### Research claim and execution boundary

**exp006 is an execution-contract experiment.** It keeps exp005's source-only examples, rank-8 LoRA recipe, Rich repository holdout, contract-first agent instruction and 3-minute issue budget. The change is that **the same offline notebook trains and creates `submission.zip` both when you Save & Run All and when Kaggle privately reruns the selected version for scoring**. This is not a claimed quality improvement over exp005.

The competition replaces its `tasks.jsonl` with hidden, label-free tasks during Notebook scoring. We therefore train only from a *separate, immutable public-development Input*, produced by the preparation notebook `00-freeze-public-dev-input.ipynb`. The training file contains published issue text and source reference patches, but no `test_patch`; the scorer's substituted competition dataset is never read for training or selection. A manifest fixes its SHA-256, row identities and repository counts before any GPU work.

**Quality boundary.** Rich next-token loss is a component signal, not solved-issue rate. The trained LoRA uses an Unsloth bitsandbytes 31B checkpoint whereas the official agent serves a Gemma 4 31B QAT model. ZIP structure and nonzero weights do not prove transfer or hidden Score. The contract-first policy still requires an issue-derived check before editing and independent verification after editing; [ExecCritic](https://arxiv.org/abs/2609.09133) motivated that policy, not a leaderboard prediction.

def is_source_path(path):
    return (path.endswith('.py') and '/test' not in path
            and not path.startswith('test') and not path.endswith('_test.py'))

def source_only_diff(patch):
    """Retain complete Python source file diffs, never test or non-Python files."""
    # Public development patches may be plain unified diffs without Git headers.
    # Add a header only after finding a source file; the learned target stays a
    # valid unified diff and the later filter still excludes tests and docs.
    has_git_headers = bool(re.search(r'^diff --git ', patch, flags=re.MULTILINE))
    boundary = r'(?=^diff --git )' if has_git_headers else r'(?=^--- (?:a/|/dev/null))'
    sections = re.split(boundary, patch, flags=re.MULTILINE)
    kept = []
    for section in sections:
        if section.startswith('--- '):
            plus = next((line[6:] for line in section.splitlines()
                         if line.startswith('+++ b/')), None)
            if plus:
                section = f'diff --git a/{plus} b/{plus}\n' + section
        if not section.startswith('diff --git '):
            continue
        plus = next((line[6:] for line in section.splitlines()
                     if line.startswith('+++ b/')), None)
        if plus and is_source_path(plus) and any(
                line.startswith('@@') for line in section.splitlines()):
            kept.append(section.rstrip('\n'))
    return '\n'.join(kept) + ('\n' if kept else '')

def source_edit_pair(patch):
    before, after, path = [], [], None
    for line in patch.splitlines():
        if line.startswith('diff --git '):
            path = None
        elif line.startswith('+++ b/'):
            path = line[6:]
            if is_source_path(path):
                before.append(f'FILE {path}')
                after.append(f'FILE {path}')
            else:
                path = None
        elif path and line.startswith('@@'):
            before.append('HUNK')
            after.append('HUNK')
        elif path and line.startswith(' '):
            before.append(line[1:]); after.append(line[1:])
        elif path and line.startswith('-') and not line.startswith('---'):
            before.append(line[1:])
        elif path and line.startswith('+') and not line.startswith('+++'):
            after.append(line[1:])
    return '\n'.join(before), '\n'.join(after)

def source_stats(patch):
    files, hunks, changed, active = 0, 0, 0, False
    for line in patch.splitlines():
        if line.startswith('diff --git '):
            active = False
        elif line.startswith('+++ b/'):
            active = is_source_path(line[6:])
            files += int(active)
        elif active and line.startswith('@@'):
            hunks += 1
        elif active and line.startswith(('+', '-')) and not line.startswith(('+++', '---')):
            changed += 1
    return files, hunks, changed

examples = []
flow = Counter()
for row in rows:
    flow['all'] += 1
    before, after = source_edit_pair(row.get('patch') or '')
    issue = row.get('problem_statement') or ''
    if not (before and after and before != after and issue):
        continue
    flow['source_edit'] += 1
    if max(len(before), len(after)) > 2600 or len(issue) > 3500:
        continue
    flow['length_bound'] += 1
    files, hunks, changed = source_stats(row.get('patch') or '')
    target = source_only_diff(row.get('patch') or '')
    assert target and 'diff --git ' in target
    examples.append(dict(id=row['instance_id'], repo=row['repo'], issue=issue,
                         before=before, after=after, target=target,
                         changed_lines=changed, source_files=files, hunks=hunks))
assert len(examples) >= 20, 'Too few bounded source edits for this notebook'
print('Usable examples:', len(examples))

<h2 style="color:#0B1F3A;border-bottom:3px solid #00B4A6;padding-bottom:6px;">3. Can two T4 GPUs train a 31B QLoRA adapter?</h2>

The competition serves `gemma-4-31b-it-qat-w4a16-ct` for inference.
