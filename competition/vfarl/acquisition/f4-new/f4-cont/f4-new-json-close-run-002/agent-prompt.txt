Problem Statement:
JSONStorage close method doesn't properly close file handle

#### Description

When using JSONStorage with caching middleware, the file handle is not properly closed after database operations. The close method sets the handle to None instead of actually closing the file.

#### Steps/Code to Reproduce

```python
import os
from tinydb import TinyDB
from tinydb.storages import JSONStorage
from tinydb.middlewares import CachingMiddleware

# Create a database with caching middleware
path = 'test.db'
with TinyDB(path, storage=CachingMiddleware(JSONStorage)) as db:
    db.insert({'key': 'value'})

# Check if file handle is properly closed
print(db._storage._handle.closed)  # Should be True but raises AttributeError
```

The issue occurs because the close method in JSONStorage sets `self._handle = None` instead of calling `self._handle.close()`. This means the file handle is never actually closed, and accessing `.closed` attribute raises an AttributeError since None doesn't have a closed attribute.

Expected behavior: The file handle should be properly closed and `db._storage._handle.closed` should return True.
Actual behavior: AttributeError is raised when trying to access the closed attribute.
