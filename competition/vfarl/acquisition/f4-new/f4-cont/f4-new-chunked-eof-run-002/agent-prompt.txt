Problem Statement:
ChunkedReader.read_eof() returns None instead of raising RemoteProtocolError

#### Description

When a chunked transfer encoding connection is closed prematurely by the peer, the ChunkedReader should raise a RemoteProtocolError indicating an incomplete chunked read. However, it currently returns None instead of raising the expected exception.

#### Steps/Code to Reproduce

```python
import h11
from h11 import Connection, SERVER, NEED_DATA

# Create a server connection and start receiving a chunked request
c = Connection(SERVER)
c.receive_data(b'POST / HTTP/1.1\r\nHost: example.com\r\nTransfer-Encoding: chunked\r\n\r\n')

# Get the request event
request = c.next_event()
assert c.next_event() is NEED_DATA

# Receive partial chunk data
c.receive_data(b'8\r\n012345')
data_event = c.next_event()
print(f"Received data: {data_event.data}")

# Simulate connection close (empty bytes)
c.receive_data(b'')

# This should raise RemoteProtocolError but doesn't
try:
    next_event = c.next_event()
    print(f"Unexpected: got {next_event} instead of exception")
except Exception as e:
    print(f"Expected exception: {e}")
```

Expected behavior: Should raise `RemoteProtocolError` with message about incomplete chunked read.
Actual behavior: Returns None or some other value instead of raising the exception.
