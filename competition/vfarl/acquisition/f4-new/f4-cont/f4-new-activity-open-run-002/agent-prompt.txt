Problem Statement:
ActivityTask missing methods after refactoring

#### Description

The ActivityTask class is missing several essential methods that were apparently removed during a refactoring. When trying to use activity tasks with heartbeat functionality, the code fails because key methods are no longer available.

#### Steps/Code to Reproduce

```python
from moto.swf.models.activity_task import ActivityTask
from moto.swf.models.workflow_execution import WorkflowExecution

# Create a workflow execution and activity task
wfe = WorkflowExecution(...)
task = ActivityTask(
    activity_id='my-activity-123', 
    activity_type='foo', 
    workflow_input='optional', 
    scheduled_event_id=117, 
    timeouts={'heartbeatTimeout': '300'}, 
    workflow_execution=wfe
)

# These methods are missing and cause AttributeError
task.reset_heartbeat_clock()  # AttributeError: 'ActivityTask' object has no attribute 'reset_heartbeat_clock'
task.first_timeout()  # AttributeError: 'ActivityTask' object has no attribute 'first_timeout'
task.open  # AttributeError: 'ActivityTask' object has no attribute 'open'
```

The missing methods include:
- `reset_heartbeat_clock()` - needed for updating heartbeat timestamps
- `first_timeout()` - needed for timeout processing 
- `open` property - needed to check if task is in an open state

These methods appear to be essential for the SWF activity task timeout and heartbeat functionality to work properly.
