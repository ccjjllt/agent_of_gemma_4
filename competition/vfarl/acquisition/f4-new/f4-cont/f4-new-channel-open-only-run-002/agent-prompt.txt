Problem Statement:
Channel operations fail with "Channel is not open" error on active channels

#### Description

When attempting to perform operations on active SSH channels, they incorrectly raise `SSHException("Channel is not open")` even when the channel is properly opened and active.

#### Steps/Code to Reproduce

```python
import paramiko

# Create SSH client and connect
client = paramiko.SSHClient()
client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
client.connect('hostname', username='user', password='pass')

# Open a channel and execute a command
transport = client.get_transport()
channel = transport.open_session()
channel.exec_command('echo "hello world"')

# This should work but raises SSHException
output = channel.recv(1024)
```

The above code raises:
```
paramiko.ssh_exception.SSHException: Channel is not open
```

Even though the channel was just opened and should be active.

#### Expected Behavior

Channel operations should work normally on active, open channels without raising exceptions about the channel not being open.

#### Actual Behavior

Operations on active channels raise `SSHException("Channel is not open")` preventing normal SSH functionality.
