Problem Statement:
Database drop_tables() method doesn't clear tables properly

When calling `drop_tables()` on a TinyDB instance, the method fails to properly clear the internal table cache, causing subsequent operations to fail with serialization errors.

#### Steps to Reproduce

```python
from tinydb import TinyDB

# Create a database and add some data
db = TinyDB('test.json')
db.drop_tables()
db.insert({'int': 1, 'char': 'a'})

# This should work but fails
db.drop_tables()
db.insert({'int': 2, 'char': 'b'})
```

The second insert operation fails with a `TypeError: Object of type Table is not JSON serializable` error.

#### Expected Behavior

After calling `drop_tables()`, the database should be completely reset and ready for new operations without any serialization issues.

#### Actual Behavior

The method writes table objects to storage instead of an empty dictionary, and doesn't clear the internal table cache, leading to serialization errors on subsequent operations.
