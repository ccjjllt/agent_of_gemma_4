## Description

I found a bug in the `FileProcessor` class where the blank line counter is decremented instead of incremented when a new blank line is visited.

## Steps to reproduce

1. Create a Python file with blank lines
2. Run flake8 on the file

## Expected behavior

The blank line counter should increase when a new blank line is encountered.

## Actual behavior

The blank line counter decreases with each blank line, eventually becoming negative. This causes incorrect reporting of blank line related issues.

Here's a simple reproduction script:

```python
from flake8.processor import FileProcessor

# Create a file processor with a file containing blank lines
file_processor = FileProcessor('-', options=None, lines=['a = 1\n', '\n', '\n'])

# Check initial blank line count
print(f"Initial blank lines: {file_processor.blank_lines}")

# Visit a new blank line
file_processor.visited_new_blank_line()

# Check the blank line count after visiting
print(f"Blank lines after visiting: {file_processor.blank_lines}")

# Expected: blank_lines should increase
# Actual: blank_lines decreases
```
