Problem Statement:
Reference generation broken for OpenAPI 3.x schemas

#### Description

When using OpenAPI 3.x specifications, schema references are being generated incorrectly. The `build_reference` function appears to be producing malformed `$ref` paths that don't follow the proper OpenAPI 3.x format.

#### Steps/Code to Reproduce

```python
from apispec import APISpec
from apispec.utils import build_reference

# Create an OpenAPI 3.0 spec
spec = APISpec(
    title="Test API",
    version="1.0.0",
    openapi_version="3.0.0"
)

# Try to build a reference to a schema component
ref = build_reference(spec.openapi_version.major, "schema", "PetSchema")
print("Generated reference:", ref)
# Expected: {"$ref": "#/components/schemas/PetSchema"}
```

The generated references don't match the expected OpenAPI 3.x format and cause issues when trying to use schema references in API specifications. This affects any code that relies on proper `$ref` generation for components like schemas, responses, parameters, etc.
