# `setdefault` method in Dict class returns incorrect values

### What happened?

I discovered that the `setdefault` method in the `Dict` class is not working as expected. When using `setdefault`, it returns incorrect values and also sets incorrect values in the dictionary.

### What did you expect to happen?

I expected `setdefault` to behave like Python's standard dictionary `setdefault` method:
- If the key exists, return the existing value
- If the key doesn't exist, set the key to the default value and return that default value

### Minimal Complete Verifiable Example

```python
from addict import Dict

# Case 1: Key doesn't exist
d = Dict()
result = d.setdefault('a', 'default_value')
print(f"Result: {result}")  # Should be 'default_value'
print(f"Dict: {d}")  # Should be {'a': 'default_value'}

# Case 2: Key already exists
d = Dict()
d.a = 'existing_value'
result = d.setdefault('a', 'default_value')
print(f"Result: {result}")  # Should be 'existing_value'
print(f"Dict: {d}")  # Should still be {'a': 'existing_value'}

# Case 3: Nested setdefault
d = Dict()
result = d.x.setdefault('y', 'nested_default')
print(f"Result: {result}")  # Should be 'nested_default'
print(f"Dict: {d}")  # Should be {'x': {'y': 'nested_default'}}
```

When running this code, the results don't match what's expected from a standard Python dictionary's `setdefault` method.

### Anything else we need to know?

This issue affects both simple and nested usage of the `setdefault` method. The current implementation seems to have the logic reversed in some cases and also appears to be using the key as the value in some scenarios instead of the provided default value.
