Problem Statement:
# Table with caption generates incorrect markdown output

## Description

I've discovered an issue with the `markdownify` library when converting HTML tables with captions to markdown. The library is adding an extra newline after the caption text, which breaks the table formatting.

## Steps to reproduce

Here's a simple example that demonstrates the issue:

```python
from markdownify import markdownify as md

html_table = """
<table>
  <caption>Caption</caption>
  <tr>
    <th>Firstname</th>
    <th>Lastname</th>
    <th>Age</th>
  </tr>
  <tr>
    <td>Jill</td>
    <td>Smith</td>
    <td>50</td>
  </tr>
</table>
"""

result = md(html_table)
print(result)
```

## Expected output

```
Caption
| Firstname | Lastname | Age |
| --- | --- | --- |
| Jill | Smith | 50 |
```

## Actual output

```
Caption

| Firstname | Lastname | Age |
| --- | --- | --- |
| Jill | Smith | 50 |
```

Notice the extra blank line between the caption and the table. This breaks the connection between the caption and the table in the markdown output.

The issue appears to be in the `convert_caption` method, which is adding an extra newline character. This causes the table to be separated from its caption, making it difficult to understand what the table represents.
