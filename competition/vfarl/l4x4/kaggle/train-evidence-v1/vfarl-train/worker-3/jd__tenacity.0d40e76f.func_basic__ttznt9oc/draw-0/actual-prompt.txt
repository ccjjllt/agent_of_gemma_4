Problem Statement:
retry_if_not_result returns inverted boolean values

#### Description

The `retry_if_not_result` condition is returning inverted boolean values - it returns `True` when it should return `False` and vice versa.

#### Steps/Code to Reproduce

```python
import tenacity

# Create a retry condition that should retry if result is NOT 1
retry_condition = tenacity.retry_if_not_result(lambda x: x == 1)

# Test with result = 2 (should retry since 2 != 1)
@tenacity.retry(retry=retry_condition, stop=tenacity.stop_after_attempt(2))
def get_two():
    return 2

# Test with result = 1 (should NOT retry since 1 == 1) 
@tenacity.retry(retry=retry_condition, stop=tenacity.stop_after_attempt(2))
def get_one():
    return 1

# This should retry but doesn't
try:
    result = get_two()
    print(f"get_two() returned: {result} (expected: should have retried)")
except tenacity.RetryError:
    print("get_two() retried as expected")

# This should not retry but does
try:
    result = get_one()
    print(f"get_one() returned: {result} (expected: should not retry)")
except tenacity.RetryError:
    print("get_one() retried unexpectedly")
```

The behavior is inverted - functions that should retry don't, and functions that shouldn't retry do.
