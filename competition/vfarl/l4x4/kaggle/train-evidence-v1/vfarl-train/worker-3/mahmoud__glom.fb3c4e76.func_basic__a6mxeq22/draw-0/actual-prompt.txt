Problem Statement:
Pipe steps executed in reverse order

#### Description

When using `Pipe` with multiple steps, the steps are being executed in reverse order instead of the expected left-to-right order.

#### Steps/Code to Reproduce

```python
from glom import glom, Pipe

# This should convert 1 -> int -> 'int' -> 'INT'
result = glom(1, Pipe('__class__', '__name__', str.upper))
print(f"Expected: 'INT', Got: {result}")

# Another example showing the issue
data = {'a': {'b': 'hello'}}
result = glom(data, Pipe('a', 'b', str.upper))
print(f"Expected: 'HELLO', Got: {result}")
```

The first example should:
1. Get `__class__` from `1` (returns `<class 'int'>`)
2. Get `__name__` from that (returns `'int'`)  
3. Apply `str.upper` to that (returns `'INT'`)

But it appears to be executing the steps in reverse order.
