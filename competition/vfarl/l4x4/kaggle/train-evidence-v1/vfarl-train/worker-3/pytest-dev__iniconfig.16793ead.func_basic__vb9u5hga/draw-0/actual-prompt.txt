Problem Statement:
# ParseError shows incorrect line number in error message

When using the `ParseError` class, the line number shown in the error message is incorrect. It's showing the line number minus 1 instead of the line number plus 1.

## To Reproduce

```python
from iniconfig.exceptions import ParseError

# Create a ParseError with line number 0
e = ParseError('filename', 0, 'hello')
print(str(e))
```

### Current output:
```
filename:-1: hello
```

### Expected output:
```
filename:1: hello
```

The issue is that the line number is being decremented instead of incremented when formatting the error message. This causes line numbers to be off by 2 from what they should be, and can even result in negative line numbers when the error is on the first line of a file.

This is particularly confusing for users trying to debug configuration issues, as they'll be looking at the wrong line in their files.
