Problem Statement:
Context manager doesn't close storage properly

When using TinyDB with a context manager, the storage is not being closed properly when exiting the context. This causes issues with file-based storages where data might not be flushed to disk.

#### Steps/Code to Reproduce

```python
import os
from tinydb import TinyDB
from tinydb.storages import JSONStorage
from tinydb.middlewares import CachingMiddleware

# Create a temporary database file
path = 'test.db'
with TinyDB(path, storage=CachingMiddleware(JSONStorage)) as db:
    db.insert({'key': 'value'})

# Check if file was written properly
statinfo = os.stat(path)
print(f"File size: {statinfo.st_size}")  # Should not be 0
print(f"Storage closed: {db._storage._handle.closed}")  # Should be True

# Try to read the data back
with TinyDB(path, storage=CachingMiddleware(JSONStorage)) as db:
    data = db.all()
    print(f"Data: {data}")  # Should contain the inserted record
```

The file size remains 0 and the storage handle is not properly closed, indicating that the data was never flushed to disk when exiting the context manager.
