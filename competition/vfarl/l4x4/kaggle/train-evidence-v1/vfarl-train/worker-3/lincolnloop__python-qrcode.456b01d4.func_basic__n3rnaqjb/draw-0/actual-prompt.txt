Problem Statement:
QR code mode detection returns wrong mode for alphanumeric data

#### Description

When generating QR codes with alphanumeric data, the mode detection is returning the wrong encoding mode. Alphanumeric strings that should use MODE_ALPHA_NUM are incorrectly being assigned MODE_NUMBER.

#### Steps/Code to Reproduce

```python
import qrcode
from qrcode.constants import MODE_ALPHA_NUM

qr = qrcode.QRCode()
qr.add_data('ABCDEFGHIJ1234567890', optimize=0)
qr.make()

print(f"Expected mode: {MODE_ALPHA_NUM}")
print(f"Actual mode: {qr.data_list[0].mode}")
```

The string 'ABCDEFGHIJ1234567890' contains both letters and numbers, so it should be encoded using alphanumeric mode (MODE_ALPHA_NUM), but it's getting assigned numeric mode (MODE_NUMBER) instead.

This affects QR code generation efficiency since alphanumeric mode can encode this type of mixed data more compactly than treating it as 8-bit byte data.
