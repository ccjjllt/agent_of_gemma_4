Problem Statement:
Switch constructor doesn't raise ValueError for empty cases

When creating a Switch with empty cases, the constructor should raise a ValueError but instead it silently adds a default case.

#### Steps/Code to Reproduce

```python
from glom.matching import Switch

# This should raise ValueError but doesn't
switch = Switch({})
print("Switch created with empty cases:", switch.cases)

# Expected behavior: should raise ValueError
# Actual behavior: creates switch with [('default', None)]
```

#### Expected Behavior

Switch constructor should raise `ValueError('expected at least one case in Switch, got: {}')` when cases is empty.

#### Actual Behavior

Switch constructor silently adds a default case `('default', default)` to the cases list instead of raising an error.
