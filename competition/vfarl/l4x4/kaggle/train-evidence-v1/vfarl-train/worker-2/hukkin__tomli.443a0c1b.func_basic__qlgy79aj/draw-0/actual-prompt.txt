Problem Statement:
TypeError when parsing TOML files with pending flags

#### Description

When parsing certain TOML files, the parser raises a `TypeError: 'int' object is not iterable` error. This appears to be related to how pending flags are handled internally during the parsing process.

#### Steps/Code to Reproduce

```python
import tomli

# This will raise TypeError: 'int' object is not iterable
toml_content = """
[table]
key = "value"
"""

result = tomli.loads(toml_content)
```

The error occurs when the parser tries to process pending flags during finalization. The issue seems to affect both valid and invalid TOML files that trigger the flag processing mechanism.

#### Expected Behavior

The parser should successfully parse valid TOML content without raising TypeError, and should raise appropriate TOMLDecodeError for invalid content.

#### Actual Behavior

Parser raises `TypeError: 'int' object is not iterable` instead of properly handling the flags or raising the expected TOML-specific errors.
