Problem Statement:
# Table header row detection fails for tables with tbody but no thead

I've discovered an issue with the table conversion in markdownify. When converting HTML tables that have a `tbody` element but no `thead` element, the first row is not properly recognized as a header row.

## Expected behavior
The first row of a table should be treated as a header row, even if the table has a `tbody` element but no `thead` element.

## Actual behavior
When a table has a `tbody` element but no `thead` element, the first row is not treated as a header row, resulting in incorrect markdown output. The separator line (with dashes) is missing, making the table invalid in markdown.

## Steps to reproduce

```python
from markdownify import markdownify as md

# HTML table with tbody but no thead
html = """
<table>
  <tbody>
    <tr>
      <th>Firstname</th>
      <th>Lastname</th>
      <th>Age</th>
    </tr>
    <tr>
      <td>Jill</td>
      <td>Smith</td>
      <td>50</td>
    </tr>
    <tr>
      <td>Eve</td>
      <td>Jackson</td>
      <td>94</td>
    </tr>
  </tbody>
</table>
"""

# Convert to markdown
result = md(html)
print(result)
```

### Output
```
| Firstname | Lastname | Age |
| Jill | Smith | 50 |
| Eve | Jackson | 94 |
```

### Expected output
```
| Firstname | Lastname | Age |
| --- | --- | --- |
| Jill | Smith | 50 |
| Eve | Jackson | 94 |
```

The issue appears to be in the logic that determines whether a row is a header row. The condition is not correctly handling tables with a `tbody` element but no `thead` element.
