Problem Statement:
XML comments are processed incorrectly

When parsing XML with comments using the `process_comments=True` option, the comments are not being processed correctly. There are two issues:

1. The whitespace stripping logic for comments is inverted - comments are only stripped when `strip_whitespace` is False, which is the opposite of the expected behavior.

2. Comments are being reversed (characters in reverse order) when they're added to the result dictionary.

Here's a simple example to reproduce the issue:

```python
import xmltodict

xml = """
<root>
  <!-- This is a comment -->
  <element>value</element>
</root>
"""

# Expected: {'root': {'#comment': 'This is a comment', 'element': 'value'}}
# Actual: {'root': {'#comment': 'tnemmoc a si sihT', 'element': 'value'}}
result = xmltodict.parse(xml, process_comments=True)
print(result)
```

The comment text "This is a comment" appears reversed as "tnemmoc a si sihT" in the output dictionary.

This affects any XML parsing that relies on comment processing.
