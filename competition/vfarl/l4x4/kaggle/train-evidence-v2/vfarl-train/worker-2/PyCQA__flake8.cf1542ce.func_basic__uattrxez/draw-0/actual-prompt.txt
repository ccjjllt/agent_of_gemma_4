Problem Statement:
StyleGuide.is_user_ignored always returns decision for hardcoded code instead of actual code

#### Description

The `is_user_ignored` method in StyleGuide is not working correctly - it's always checking against a hardcoded code value instead of the actual code parameter passed to the method.

#### Steps/Code to Reproduce

```python
from flake8.style_guide import StyleGuide
from flake8.options.manager import OptionManager
from flake8.formatting.base import BaseFormatter

# Create a basic style guide setup
option_manager = OptionManager()
options = option_manager.parse_args(['--ignore=E123'])
formatter = BaseFormatter(options)
guide = StyleGuide(options, formatter, None)

# This should return True since E123 is ignored
result1 = guide.is_user_ignored('E123')
print(f"E123 ignored: {result1}")  # Expected: True

# This should return False since E124 is not ignored  
result2 = guide.is_user_ignored('E124')
print(f"E124 ignored: {result2}")  # Expected: False

# But both return the same result due to the bug
```

The issue is that regardless of what code you pass to `is_user_ignored()`, it always checks the decision for the same hardcoded value instead of using the actual code parameter.
