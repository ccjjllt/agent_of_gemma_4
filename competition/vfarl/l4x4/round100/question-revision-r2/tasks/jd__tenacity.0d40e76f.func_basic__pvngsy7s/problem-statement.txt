wait_combine returns double the expected wait time

When combining wait strategies, the returned delay is twice the sum of their configured delays. The same problem affects the `+` operator.

A bounded reproduction using the RetryCallState API in this repository:

```python
from tenacity import Retrying, RetryCallState, wait_combine, wait_fixed

retrying = Retrying(wait=wait_combine(wait_fixed(2), wait_fixed(3)))
state = RetryCallState(retrying, None, (), {})
print(retrying.wait(state))

combined = wait_fixed(2) + wait_fixed(3)
print(combined(state))
```

Both delays should be 5.0 seconds. They currently return 10.0 seconds. Combining strategies should preserve the sum of the component wait times, including combinations containing a random wait strategy.
