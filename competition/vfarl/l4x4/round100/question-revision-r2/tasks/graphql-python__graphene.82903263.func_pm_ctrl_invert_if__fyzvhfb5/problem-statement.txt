GenericScalar.parse_literal does not decode GraphQL object literals

Input object literals should recursively decode their fields into the corresponding Python dictionary, while preserving the scalar's existing primitive and list behavior.

```python
from graphene.types.generic import GenericScalar
from graphql import parse_value

value = GenericScalar.parse_literal(parse_value('{hello: "world"}'))
print(value)
```

Expected: {'hello': 'world'}. The current result is None.

This concerns parsing an input ObjectValueNode. An output-only query whose resolver returns a dictionary follows serialization and does not reproduce this bug. GenericScalar is imported from graphene.types.generic in this repository version.
