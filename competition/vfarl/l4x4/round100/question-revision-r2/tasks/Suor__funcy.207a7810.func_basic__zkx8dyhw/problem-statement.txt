`interpose` function produces incorrect output order

#### Description

The `interpose` function is not working as expected - it's placing the separator in the wrong positions, dropping the first input item, and leaving a trailing separator.

#### Steps/Code to Reproduce

```python
from funcy import interpose

# Expected: ['a', '.', 'b', '.', 'c']
# Actual: ['.', 'b', '.', 'c', '.']
result = list(interpose('.', 'abc'))
print("Expected:", ['a', '.', 'b', '.', 'c'])
print("Actual:  ", result)
```

The function should alternate between sequence items and separators, starting with a sequence item, but instead it loses the first item, starts with a separator, and ends with a separator.
