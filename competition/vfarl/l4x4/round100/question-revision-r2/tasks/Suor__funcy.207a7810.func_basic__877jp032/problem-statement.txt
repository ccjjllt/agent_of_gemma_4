flip function returns incorrect result

#### Description

The `flip` function is not properly swapping keys and values in mappings. When called on a dictionary, it returns a lazy map object instead of a dictionary with swapped keys and values. Evaluating that iterator for the one-character keys in this example can raise a ValueError.

#### Steps/Code to Reproduce

```python
from funcy import flip

# Expected behavior: flip should swap keys and values
result = flip({'a': 1, 'b': 2})
print("Result:", result)
print("Expected: {1: 'a', 2: 'b'}")

# The function should return a dict with swapped key-value pairs
# but currently returns something else
```

The function should return `{1: 'a', 2: 'b'}` but doesn't produce the expected output.
