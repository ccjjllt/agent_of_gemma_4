`without` function returns items that should be excluded instead of filtering them out

#### Description

The `without` function is behaving incorrectly - it's returning the items that should be excluded rather than filtering them out from the sequence.

#### Steps/Code to Reproduce

```python
from funcy import without, lwithout

# This should return [2, 3, 4] but returns [1, 1, 0, 1] instead
result = list(without([1, 2, 1, 0, 3, 1, 4], 0, 1))
print("Got:", result)
print("Expected: [2, 3, 4]")

# Same issue with lwithout
result2 = lwithout([1, 2, 1, 0, 3, 1, 4], 0, 1)
print("Got:", result2)
print("Expected: [2, 3, 4]")
```

The function is supposed to iterate over the sequence and skip the specified items, but it's doing the opposite - yielding only the items that match the exclusion criteria.
