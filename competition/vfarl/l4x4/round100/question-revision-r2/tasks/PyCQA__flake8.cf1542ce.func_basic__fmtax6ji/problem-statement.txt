FileProcessor blank-line visits decrease the blank-line count

Visiting a new blank line should increase the FileProcessor blank-line count. A freshly initialized processor starts at zero; after one visit the count should be one, not negative.

The options object must contain the fields consumed by this version of FileProcessor:

```python
from argparse import Namespace
from flake8.processor import FileProcessor

options = Namespace(
    hang_closing=False,
    indent_size=4,
    max_line_length=79,
    max_doc_length=None,
    verbose=0,
)
processor = FileProcessor("-", options, lines=["a = 1\n", "\n"])
assert processor.blank_lines == 0
processor.visited_new_blank_line()
assert processor.blank_lines == 1
```

Actual: the final count is -1. This produces incorrect state for checks that rely on the number of blank lines.
