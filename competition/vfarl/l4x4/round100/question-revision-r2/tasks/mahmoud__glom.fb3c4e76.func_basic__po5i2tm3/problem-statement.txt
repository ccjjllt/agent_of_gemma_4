Min aggregation loses the minimum when larger values follow

The Min aggregator should report the minimum encountered in the input. It currently reports a later input value even when that value is larger than the minimum already encountered.

```python
from glom import glom
from glom.grouping import Group, Min

result = glom([1, 0, 1], Group(Min()))
print(result)
```

Expected output: `0`.

Current output: `1`.

This example contains a single minimum value. The larger value that follows it must not replace the reported minimum.
