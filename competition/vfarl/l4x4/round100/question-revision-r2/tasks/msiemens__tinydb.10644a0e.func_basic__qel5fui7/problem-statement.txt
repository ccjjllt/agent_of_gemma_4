Explicit TinyDB.close inside a context closes the storage twice

Calling `close()` explicitly inside a TinyDB context should close the storage once. Exiting that context should complete successfully.

```python
from tinydb import TinyDB

class TestStorage:
    def __init__(self):
        self.closed = False

    def read(self):
        return {}

    def write(self, data):
        pass

    def close(self):
        if self.closed:
            raise RuntimeError("Storage already closed!")
        self.closed = True

with TinyDB(storage=TestStorage) as db:
    db.close()
```

The `storage` argument above is the storage class accepted by TinyDB. The current code raises `RuntimeError("Storage already closed!")` on context exit. The explicit close and context cleanup should work together without closing this storage twice.
