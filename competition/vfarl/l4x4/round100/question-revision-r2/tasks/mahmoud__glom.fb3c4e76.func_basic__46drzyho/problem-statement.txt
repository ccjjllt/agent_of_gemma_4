Switch should reject an empty collection of cases

Constructing a Switch without any cases should raise ValueError.

```python
from glom.matching import Switch

try:
    Switch({})
except ValueError:
    print("ValueError")
else:
    print("The empty cases were unexpectedly accepted")
```

The expected result is a ValueError from construction. The current constructor accepts the empty cases and creates a default case instead. No particular error-message spelling is required here.
