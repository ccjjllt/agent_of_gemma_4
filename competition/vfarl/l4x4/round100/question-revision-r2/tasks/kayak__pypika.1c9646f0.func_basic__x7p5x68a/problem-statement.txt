MySQLQueryBuilder.__copy__ returns None

Copying a MySQL query builder should return a distinct MySQLQueryBuilder with the same query state. It currently returns None. This also breaks query-building operations that copy a builder internally, sometimes before a chained query has finished being constructed.

A direct, bounded reproduction avoids requiring a working query chain first:

```python
from copy import copy
from pypika.dialects import MySQLQueryBuilder

query = MySQLQueryBuilder()
copied_query = copy(query)
print(copied_query is None)
print(type(copied_query).__name__)
```

Expected output:

```text
False
MySQLQueryBuilder
```

Current output:

```text
True
NoneType
```

Normal MySQL query construction and copying should remain usable.
