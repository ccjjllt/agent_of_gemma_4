Component registration has incorrect eager and lazy behavior.

Ordinary components should be available in the generated specification immediately after registration. Components registered with lazy=True should remain deferred until they are referenced. Currently ordinary components can be absent from the output while deferred components appear too early.

For example:

```python
from apispec import APISpec

spec = APISpec(title="Test", version="1.0", openapi_version="3.0.0")
spec.components.schema("Pet", {"type": "object"})
print("Pet" in spec.to_dict().get("components", {}).get("schemas", {}))
# Expected: True
```

Preserve correct reference resolution as components are registered and used. The public registration API should continue to protect caller-owned component definitions from unintended changes.
