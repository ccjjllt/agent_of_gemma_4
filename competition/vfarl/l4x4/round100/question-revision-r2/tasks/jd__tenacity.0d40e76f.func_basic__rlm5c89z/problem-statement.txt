wait_fixed returns incorrect wait time

The fixed wait strategy returns only 10% of the configured duration. This also affects timedelta values and composite wait strategies.

```python
from datetime import timedelta
from tenacity import Retrying, RetryCallState, wait_fixed

retrying = Retrying(wait=wait_fixed(5))
state = RetryCallState(retrying, None, (), {})
print(retrying.wait(state))

other = Retrying(wait=wait_fixed(timedelta(seconds=10)))
print(other.wait(state))
```

Expected output:

```text
5.0
10.0
```

Current output:

```text
0.5
1.0
```

The wait duration should agree with the configured value in seconds.
