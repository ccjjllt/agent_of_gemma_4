Sequence partitioning and chunking use incorrect offsets and steps

Partitioning should keep only complete groups; chunking should also retain the final short group. Existing explicit-step behavior should preserve source order.

```python
from funcy import lpartition, lchunks

print(lpartition(2, [0, 1, 2, 3, 4]))
# Expected: [[0, 1], [2, 3]]
# Current:  [[1, 2], [2, 3]]

print(lchunks(2, [0, 1, 2, 3, 4]))
# Expected: [[0, 1], [2, 3], [4]]
# Current:  [[1, 2], [2, 3], [3, 4], [4], []]
```

For lpartition(2, 1, [0, 1, 2, 3]), the expected overlapping groups are [[0, 1], [1, 2], [2, 3]]. The current implementation instead raises ValueError: range() arg 3 must not be zero. Fix the sequence grouping behavior while preserving iterator and tail semantics.
