Problem Statement:
FixedOffset timezone returns wrong offset sign

#### Description

When using FixedOffset timezone objects, the UTC offset is returned with the wrong sign. This causes datetime formatting to produce incorrect timezone offset strings.

#### Steps/Code to Reproduce

```python
from datetime import datetime, time
from isodate.tzinfo import FixedOffset
from isodate import time_isoformat, datetime_isoformat

# Create a timezone with +1 hour offset
tz_plus_one = FixedOffset(1, 0, '+01:00')

# Create time and datetime objects with this timezone
test_time = time(15, 27, 46, tzinfo=tz_plus_one)
test_datetime = datetime(1985, 4, 12, 10, 15, tzinfo=tz_plus_one)

# Format them - should show +01:00 but shows -01:00 instead
print("Time formatting:")
print(f"Expected: 15:27:46+01:00")
print(f"Actual:   {time_isoformat(test_time, '%H:%M:%S%Z')}")

print("\nDatetime formatting:")  
print(f"Expected: 1985-W15-5T10:15+01")
print(f"Actual:   {datetime_isoformat(test_datetime, '%Y-W%W-%wT%H:%M%h')}")
```

The timezone offset appears with the opposite sign - positive offsets show as negative and vice versa.
