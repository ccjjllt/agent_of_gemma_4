Schema equality incorrectly rejects equivalent schemas.

Two Schema values should compare equal when their names and parent-schema values are equal. Different names or different parent values should remain unequal. Table equality should continue to use these schema values.

```python
from pypika import Schema

left = Schema("a", parent=Schema("p"))
right = Schema("a", parent=Schema("p"))
print(left == right)  # Expected: True; currently False

print(Schema("a") == Schema("b"))  # Expected: False
```

The current failure is that equivalent values are considered different.
