lpluck returns map objects instead of list when key is iterable

#### Description

When using `lpluck` with a single key, it returns map objects instead of the expected list of values.

#### Steps/Code to Reproduce

```python
from funcy import lpluck

data = [{'a': 1, 'b': 2}, {'a': 10, 'b': 2}]
result = lpluck('a', data)
print(result)
# Expected: [1, 10]
# Actual: [<map object at 0x...>]
```

The function should return a list of values extracted from each mapping, but instead returns a list containing map objects.
