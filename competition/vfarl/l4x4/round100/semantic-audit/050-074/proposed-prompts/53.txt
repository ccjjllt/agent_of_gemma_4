Component reference generation is incorrect.

The public build_reference API takes component_type, openapi_major_version, and component_name in that order. For example:

```python
from apispec.utils import build_reference

print(build_reference("schema", 3, "PetSchema"))
# Expected: {"$ref": "#/components/schemas/PetSchema"}
```

Use the appropriate reference namespace for the supported OpenAPI version and keep the component name unchanged. OpenAPI 2.x schema references should retain their definitions namespace. The current implementation can raise a KeyError or produce the wrong namespace and a reversed component name.
