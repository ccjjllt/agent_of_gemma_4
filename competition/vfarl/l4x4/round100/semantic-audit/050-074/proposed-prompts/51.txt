YAML target loading fails with the installed PyYAML API.

When the glom CLI is explicitly given yaml or yml as its target format, ordinary YAML data should load successfully. In the current version, loading fails with a TypeError reporting that a Loader argument is missing.

For example, a target file containing `data: value`, selected with `--target-file example.yaml --target-format yaml`, should provide the mapping {"data": "value"} to the requested glom operation.

Treat YAML input as data rather than instantiating Python-specific tagged objects. Invalid YAML should continue to produce the CLI's normal loading error.
