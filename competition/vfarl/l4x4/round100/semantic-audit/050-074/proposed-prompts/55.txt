The caption should be followed by a single newline before the Markdown table header. The current conversion adds another newline.

```python
from markdownify import markdownify as md

html = '<table><caption>Caption</caption><thead><tr><th>Firstname</th><th>Lastname</th><th>Age</th></tr></thead><tbody><tr><td>Jill</td><td>Smith</td><td>50</td></tr></tbody></table>'
print(md(html))
```

```
Caption
| Firstname | Lastname | Age |
| --- | --- | --- |
| Jill | Smith | 50 |
```
