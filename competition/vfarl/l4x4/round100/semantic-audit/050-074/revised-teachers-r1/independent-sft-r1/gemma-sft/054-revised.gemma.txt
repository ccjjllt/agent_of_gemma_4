A table inside tbody without thead can acquire an unwanted empty header.

When there is no explicit thead and the first row contains td cells, that first row should be used as the Markdown header row. It should not be preceded by an empty header row.

```python
from markdownify import markdownify as md

html = '<table><tbody><tr><td>Firstname</td><td>Lastname</td><td>Age</td></tr><tr><td>Jill</td><td>Smith</td><td>50</td></tr></tbody></table>'
print(md(html))
```

The table should begin with:

```
| Firstname | Lastname | Age |
| --- | --- | --- |
| Jill | Smith | 50 |
```

The current output inserts an empty header and its separator before the Firstname row.
