Problem Statement:
FileUpload.save() creates files in wrong directory when destination is a directory

When using `FileUpload.save()` with a directory path as the destination, the file gets created in the wrong location due to incorrect path joining.

#### Steps/Code to Reproduce

```python
import tempfile
import os
from bottle import FileUpload

# Create a test file upload
with open('test.txt', 'w') as f:
    f.write('test content')

fu = FileUpload(open('test.txt', 'rb'), 'testfile', 'test.txt')

# Try to save to a directory
dirpath = tempfile.mkdtemp()
fu.save(dirpath)

# Expected: file should be saved as dirpath/test.txt
# Actual: file gets saved in wrong location
```

The issue occurs because the path joining logic is reversed - instead of joining the directory with the filename, it joins the filename with the directory, resulting in an incorrect file path.

Additionally, when trying to save to an existing file without the overwrite flag, the method silently continues instead of raising an IOError as expected.
