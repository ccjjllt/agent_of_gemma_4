Problem Statement:
_flatten function returns elements in the wrong nested order

#### Description

The `_flatten` utility function in `pyparsing.util` is returning flattened elements in the wrong order compared to the source nesting.

#### Steps/Code to Reproduce

```python
from pyparsing.util import _flatten

# Simple nested list
nested = [1, [2, 3], 4]
result = _flatten(nested)
print(f"Input: {nested}")
print(f"Output: {result}")
print(f"Expected: [1, 2, 3, 4]")

# More complex nesting
complex_nested = [1, [2, [3, 4]], 5]
result2 = _flatten(complex_nested)
print(f"Input: {complex_nested}")
print(f"Output: {result2}")
print(f"Expected: [1, 2, 3, 4, 5]")
```

The function is not preserving source order across nested elements. For example, `[1, [2, 3], 4]` becomes `[3, 2, 4, 1]` instead of the expected `[1, 2, 3, 4]`.

This affects various parsing operations that rely on the flatten utility, particularly transform operations and regex substitutions where element order matters.
