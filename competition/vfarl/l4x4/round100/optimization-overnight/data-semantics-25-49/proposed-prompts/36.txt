ROLLUP generates incorrect SQL with CUBE instead of ROLLUP

#### Description

When using the `rollup()` method on queries, the generated SQL contains `WITH CUBE` instead of the expected `WITH ROLLUP`.

#### Steps/Code to Reproduce

```python
from pypika import Query, Table

table = Table('abc')
q = Query.from_(table).select(table.foo).rollup(table.foo, vendor='mysql')
print(str(q))
```

**Expected output:**
```sql
SELECT "foo" FROM "abc" GROUP BY "foo" WITH ROLLUP
```

**Actual output:**
```sql
SELECT "foo" FROM "abc" GROUP BY "foo" WITH CUBE
```

The reproduction above exercises the vendor="mysql" path that emits a WITH ROLLUP clause. The generated SQL should use WITH ROLLUP for that path.
