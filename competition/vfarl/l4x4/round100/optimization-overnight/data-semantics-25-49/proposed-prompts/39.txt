MarkdownRenderer crashes on empty list items

Rendering Markdown back to Markdown with `MarkdownRenderer` crashes with an IndexError when a list contains an empty item.

```python
from mistune import create_markdown
from mistune.renderers.markdown import MarkdownRenderer

render = create_markdown(renderer=MarkdownRenderer())
text = "- list\n- \n"
print(repr(render(text)))
```

The rendering should complete and preserve the empty list item. For this input, the expected returned Markdown is `"- list\n- \n"`. The current MarkdownRenderer raises `IndexError: list index out of range`.
