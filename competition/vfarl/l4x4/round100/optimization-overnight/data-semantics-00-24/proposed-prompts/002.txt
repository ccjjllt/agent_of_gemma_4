StyleGuide.should_report_error does not honor the requested error code

The method available in this version is StyleGuide.should_report_error(code). It returns a Decision enum, not a boolean. It should apply the configured selection and ignore rules to the code supplied by the caller.

```python
from argparse import Namespace
from flake8.style_guide import Decision, StyleGuide

options = Namespace(
    select=["E"],
    ignore=["E123"],
    extend_select=None,
    extend_ignore=None,
    extended_default_select=[],
    extended_default_ignore=[],
)
guide = StyleGuide(options, formatter=None, stats=None)
assert guide.should_report_error("E123") is Decision.Ignored
assert guide.should_report_error("E124") is Decision.Selected
```

Expected: E123 is ignored, while E124 is selected for reporting.
Actual: both calls receive the ignored decision. Preserve the Decision return contract so callers can distinguish Decision.Selected from Decision.Ignored by identity.
