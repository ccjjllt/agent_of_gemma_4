Route.reset removes route attributes after plugins have been applied

Plugins may attach state to a route while preparing its callback. Resetting that prepared route should invalidate its prepared callback without deleting unrelated route attributes.

Plugin application is lazy, so the reproduction prepares the route before inspecting plugin state:

```python
import bottle

class Plugin:
    def apply(self, callback, route):
        route.plugin_data = "important_data"
        return callback

app = bottle.Bottle()
app.install(Plugin())

@app.route("/")
def hello():
    return "Hello World"

route = app.routes[0]
route.prepare()
assert route.plugin_data == "important_data"
route.reset()
assert getattr(route, "plugin_data", None) == "important_data"
```

Expected: plugin_data remains available after reset.
Actual: it is missing after reset. Merely registering a route does not establish that a plugin's apply method has already run.
