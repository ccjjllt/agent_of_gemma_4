Duration.totimedelta should reject simultaneous start and end anchors

Duration.totimedelta accepts either a start anchor or an end anchor. Supplying both must raise ValueError with the message "only start or end allowed".

```python
from datetime import datetime
from isodate import Duration

duration = Duration(days=10)
try:
    duration.totimedelta(
        start=datetime(2023, 1, 1),
        end=datetime(2023, 1, 15),
    )
except ValueError as exc:
    assert str(exc) == "only start or end allowed"
else:
    raise AssertionError("Both anchors must be rejected")
```

Actual: this example raises TypeError about adding two datetime values, instead of the required ValueError. Conversion with a single anchor should continue to produce a timedelta representing this duration relative to that anchor; the current start-anchor calculation is also incorrect.
