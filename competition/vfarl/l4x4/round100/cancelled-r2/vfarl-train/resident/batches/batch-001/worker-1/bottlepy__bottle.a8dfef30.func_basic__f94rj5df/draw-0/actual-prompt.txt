Problem Statement:
Route.reset() clears entire __dict__ breaking plugin functionality

#### Description

When `Route.reset()` is called, it now clears the entire `__dict__` instead of just removing the 'call' key. This breaks plugin functionality because plugins may store important attributes on the route object that get wiped out.

#### Steps/Code to Reproduce

```python
import bottle

class TestPlugin(object):
    def apply(self, callback, route):
        # Plugin stores something on the route
        route.plugin_data = "important_data"
        return callback

app = bottle.Bottle()
app.install(TestPlugin())

@app.route('/')
def hello():
    return "Hello World"

# Get the route object
route = app.routes[0]

# Plugin data should be there
print("Before reset:", getattr(route, 'plugin_data', 'MISSING'))

# Reset the route (this happens internally)
route.reset()

# Plugin data is now gone
print("After reset:", getattr(route, 'plugin_data', 'MISSING'))
```

Expected output:
```
Before reset: important_data
After reset: important_data
```

Actual output:
```
Before reset: important_data
After reset: MISSING
```

The issue affects any plugin that stores state on route objects, causing them to lose their configuration or cached data when routes are reset.
