Problem Statement:
wait_combine returns double the expected wait time

#### Description

When using `wait_combine` to combine multiple wait strategies, the returned wait time is double what it should be. This affects all combinations of wait strategies and makes retry delays much longer than expected.

#### Steps/Code to Reproduce

```python
import tenacity

# Create a retrying instance with combined wait strategies
r = tenacity.Retrying(wait=tenacity.wait_combine(tenacity.wait_random(0, 3), tenacity.wait_fixed(5)))

# Check the wait time - should be between 5 and 8 seconds
retry_state = tenacity.RetryCallState(retry_object=r, outcome=None, next_action=None)
retry_state.attempt_number = 1
retry_state.seconds_since_start = 5

wait_time = r.wait(retry_state)
print(f"Wait time: {wait_time}")
# Expected: between 5.0 and 8.0
# Actual: between 10.0 and 16.0 (double the expected)
```

The same issue occurs when using the `+` operator to combine wait strategies:

```python
r = tenacity.Retrying(wait=tenacity.wait_random(0, 3) + tenacity.wait_fixed(5))
wait_time = r.wait(retry_state)
print(f"Wait time: {wait_time}")
# Expected: between 5.0 and 8.0  
# Actual: between 10.0 and 16.0 (double the expected)
```

This makes retry operations wait much longer than intended, significantly impacting application performance and user experience.
