Problem Statement:
# from_html_one() doesn't raise ValueError when multiple tables are found

## Description

When using `from_html_one()` with HTML code containing multiple tables, the function doesn't raise a ValueError as expected. Instead, it just returns the first table found.

The following code doesn't raise an error when it should:

```python
from prettytable import from_html_one

html_with_multiple_tables = """
<table>
  <tr><th>Header1</th><th>Header2</th></tr>
  <tr><td>Data1</td><td>Data2</td></tr>
</table>
<table>
  <tr><th>Header3</th><th>Header4</th></tr>
  <tr><td>Data3</td><td>Data4</td></tr>
</table>
"""

# This should raise a ValueError but doesn't
table = from_html_one(html_with_multiple_tables)
print(table)
```

According to the function's docstring, it should only work with HTML code containing a single table and raise a ValueError if multiple tables are found.
